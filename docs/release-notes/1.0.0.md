mdview 1.0: crash reports, a Mac version that updates itself, and the page for mdedit's new preview pane.

## New

- **macOS** (Apple silicon and Intel; first added to 0.5.1) now updates itself like the Windows and Linux versions, and text inserted from Emoji & Symbols or dictation reaches the text fields.
- **Crash reports.** If mdview ever crashes, it writes a short report, and on the next start a bar offers to open or copy it, so it can be sent along with a bug report. A report holds the error and the program's state in sizes only: never the document's text or file names. Nothing is sent anywhere.
- **Text being composed in an input method** (Japanese, Chinese, Korean and others) is shown where it will be typed, in the find box, the command palette and the other text fields.
- **`mdview --preview-server`** draws the page for the preview pane of mdedit 1.0, the companion editor.

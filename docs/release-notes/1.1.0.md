mdview 1.1.0: click a large diagram to open it at a reading size, and the notes library.

## New

- **Click a large diagram to read it.** A Mermaid diagram the page had to shrink to its column now opens over the window when clicked, at twice the size the page showed it, on a screen at any scale: scroll to zoom (from a fifth of the page's size to eight times it), drag to pan, and Esc or the close button to go back. +, - and 0 zoom at the centre and fit the whole diagram, however large it is; on a Mac a pinch zooms the diagram. The view closes when the page under it changes: another tab, the file read again, or the theme.

- **The notes library, read-only.** The Files pane has a second face showing mdedit's notes library: groups, sections and notes; a click opens a note in a tab, a note whose file is gone is marked, and the palette lists the notes by title, each under its own file's name. The window does not wait for the library's folder before it shows the page.

- **Add this file to the notes library.** On a tab's menu, on the page's menu and in the command palette, with a question the first time: one link is written into one of mdedit's library files, and the note itself is not changed. A library file that mdedit saved at that moment, or one that is not UTF-8 text, is left as it is, and the status line says why.

## Fixed

- **Files opened from mdedit.** A window showing files mdedit asked for, or placed beside mdedit, no longer looks at the disk for each of them on every turn of its loop. A file mdedit asked to preview that could not be opened is told closed at once, so mdedit's preview of it ends.
- **mdedit's preview pane.** A click on a task box just as mdedit sends what was typed is no longer applied to the new text, and the pane follows the caret. A pane asked for at more than 8192 pixels a side is drawn at 8192, and a malformed message is refused before any memory is set aside for it.

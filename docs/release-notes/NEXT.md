## What is new

- Rounded window corners, 8 px by default (Settings > Window corners: Square, Small or Round).
  Windows 11 draws them itself; on Wayland the window draws its own corners and shadow. Windows 10
  and windows the desktop draws opaque stay square.
- The outline follows the page as you scroll, and leaves the list alone while you are using it.
- Back and Forward are in the command palette and the Keyboard shortcuts list (Alt+Left,
  Alt+Right).
- A burst of file changes in the open folder (a git checkout) refreshes the Files pane once.
- Copying text from a page also puts it on the clipboard as HTML, so pasting into Word,
  LibreOffice or a mail keeps headings, emphasis, links, lists, tables and code. Plain-text pastes
  are unchanged.
- Code blocks have a copy button: point at one and click to copy its code, or use "Copy code block"
  in the command palette.
- Resting the pointer on a footnote, or on a link to a heading or to another local Markdown file,
  shows a small card with its text; a setting turns it off.
- Find in folder searches the Markdown files of the open folder and opens a result at its match
  (menu "Find in folder..." and the command palette).
- Export as HTML saves a document as one self-contained page; Print opens a printable copy in
  your browser (right-click a tab, or the command palette).
- Present (Shift+F5, the "⋯" menu and the command palette) shows a document as full-screen
  slides, cut at its horizontal rules or else at its level 1 and 2 headings; Escape returns to
  the page where you left it.
- A document that mdedit has not saved yet can be previewed: it appears in a tab under the
  editor's name, follows the typing, and becomes the file's tab when it is saved. Needs the
  mdedit of the same release.
- The side-by-side preview follows the caret inside long paragraphs, lists, code blocks and
  tables, not only from block to block. Needs the mdedit of the same release for paragraphs
  written as one long line.
- Windows 11: an optional frosted window. Settings > Window backdrop (Mica or Acrylic) lets the
  system material show through the bars and the side panes. Off by default.
- After an update is installed, the bar has a Restart button that closes mdview and starts the
  new version.
- Fixed: "Close window" from the taskbar closed the window only when the pointer next moved
  over it.

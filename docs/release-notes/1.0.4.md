mdview 1.0.4: leave out tabs you barely looked at, and Settings in categories.

## New

- **Don't reopen tabs barely looked at.** At start, tabs you looked at for less than a number of seconds in all are not reopened. Only the time the tab was in front of the focused window counts; a minimized window or another program in front does not. Pinned tabs and the tab you left on always come back. Off by default: Settings, Tabs, "Don't reopen tabs barely looked at" and "Looked at for less than" (10 seconds by default). The same setting as in mdedit 1.2.1.

## Changed

- **Settings** has categories, as mdedit's: a list at the left (Page, Content, Tabs, Updates, and System where mdview can be made the default), and the dialog is a little shorter.
- **One window per settings folder.** A launch made while mdview is still starting hands its files to that window instead of opening a second one on the same session.
- **The session is never overwritten when it cannot be read.** If the session file cannot be read at start (another program has it open), mdview runs without it for that window, says so, and leaves the file as it is, instead of starting empty and saving the empty session over your tabs and pins.

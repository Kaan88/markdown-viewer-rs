# mdview 1.2.2 against 1.2.1, after the release

Measured 2026-11-28 on the Windows PC, 9 interleaved runs of the published Windows zips (each exe
with its own `mdview-engine.exe`): A is 1.2.1, B is 1.2.2. `fixtures/showcase.md`, the default
window, `--no-session` and `--behind` on every start, and for every start a fresh scratch
`MDVIEW_SETTINGS` and `MDEDIT_SETTINGS`. Per run and build, as in
`2026-11-24-1.0.6-against-1.0.5.md`: a start with `MDVIEW_STARTUP_TRACE` (first frame; private
memory and working set at 3 s; CPU from 3 s to 6 s; then closed), and a start with
`--scroll-steps 300`. The script was kept outside the repository.

# Home

The start of a small set of notes that link to each other with wiki-links.

- [[Recipes]] is a plain link to a note in this folder.
- [[Recipes|What to cook]] shows other text.
- [[Recipes#Soup]] goes to a heading, and [[Recipes#Soup|the soup]] names it.
- [[#Table]] stays in this document.
- [[projects/Plan]] is a path from the root; [[Plan]] finds a note by name (two are equally near, so the first by path: the archived one).
- [[Shopping list]] has no note yet, and neither has [[projects/Budget|the budget]].
- An ordinary link to [the notes](projects/Notes.md#open-questions) still works.

`[[Recipes]]` in a code span is not a link, and neither is this:

```
[[Recipes]] in a code block
```

![[Recipes]] is an embed, which stays as written.
